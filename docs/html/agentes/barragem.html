agentes.barragem

Agente 1 — Operador da Barragem (existe um só).

A negociação da descarga é uma máquina de estados (FSMBehaviour), uma por negociação, com os estados do guia (docs/gaia_detalhado.md, secção 9.4):

PROPOR -> AGUARDAR -> ENCERRAR
             |
             +-> REFORMULAR -> PROPOR (outra rodada) ou ENCERRAR
  • PROPOR: envia o plano (caudal, atraso, duração) aos três líderes.
  • AGUARDAR: recolhe as respostas da rodada. Quem não responde a tempo conta como "não". Há maioria? Fim. Senão, e se ainda há rodadas, reformula.
  • REFORMULAR: baixa o caudal para a contraproposta mais restritiva dos líderes.
  • ENCERRAR: fecha a negociação e submete a proposta final à votação.

A votação é separada da negociação (CoordenadorVotacao, secção 5.2 do guia): um OneShotBehaviour (Votacao) envia a proposta final aos líderes no protocolo votacao, recolhe os votos e aprova com pelo menos 2 em 3. Cada líder tem um voto por negociação e quem não responde a tempo vota contra. Só depois a barragem executa a descarga aprovada.

Segurança e contingência (secção 5.2 do guia): a votação nunca autoriza uma operação insegura, por isso a barragem valida o plano de novo, com o estado atual, depois da aprovação (validar_execucao). Sem acordo, ou em emergência, aplica um procedimento de contingência pré-definido (executar_contingencia), que respeita os limites técnicos e informa os líderes:

  • sem acordo (voto rejeitado ou plano aprovado inseguro) e reservatório a NIVEL_CONTINGENCIA_RESERVATORIO ou mais;
  • emergência: reservatório a NIVEL_EMERGENCIA_RESERVATORIO ou mais, sem negociação nem votação.

O número máximo de rodadas é MAX_RODADAS (config.py).

131def reformular(plano, respostas):
132    """Cria o plano da rodada seguinte a partir das contrapropostas dos líderes.
133
134    Adota a contraproposta mais restritiva (o menor caudal), porque é a que
135    mais líderes conseguem aceitar. Só devolve um plano novo se o caudal baixar.
136
137    Args:
138        plano (dict): Plano da rodada que acabou.
139        respostas (dict): Respostas dos líderes (ver `Negociacao.respostas`).
140
141    Returns:
142        dict | None: O novo plano, ou None se ninguém contrapropôs ou se a
143        contraproposta não baixa o caudal (a negociação não pode avançar).
144    """
145    caudais = [r["contraproposta"]["caudal"] for r in respostas.values()
146               if r["contraproposta"]]
147    if not caudais:
148        return None
149    novo = dict(plano, caudal=round(min(caudais), 1))
150    if novo["caudal"] >= plano["caudal"]:
151        return None
152    return novo

155def resumo_respostas(respostas):
156    """Texto curto com a resposta de cada bairro, como "A:não B:sim C:sem resposta".
157
158    Args:
159        respostas (dict): Respostas dos líderes (ver `Negociacao.respostas`).
160
161    Returns:
162        str: Uma entrada por líder, pela ordem alfabética.
163    """
164    def texto(r):
165        """Texto de uma resposta para o registo.
166
167        Args:
168            r (dict): Resposta de um líder (`aceita`, `sem_resposta`...).
169
170        Returns:
171            str: "sem resposta", "sim" ou "não".
172        """
173        if r.get("sem_resposta"):
174            return "sem resposta"
175        return "sim" if r["aceita"] else "não"
176    return " ".join(f"{nome[-1].upper()}:{texto(r)}"
177                    for nome, r in sorted(respostas.items()))

197async def executar_contingencia(comportamento, motivo):
198    """Aplica o procedimento de contingência da barragem (secção 5.2 do guia).
199
200    A contingência é um plano pré-definido (`DamOperator.plano_contingencia`)
201    que respeita os limites técnicos e não precisa de votação. Antes de abrir
202    as comportas passa pela mesma validação de segurança. Informa os líderes
203    e os operadores.
204
205    Args:
206        comportamento: O behaviour que envia as mensagens (usa o seu `send`).
207        motivo (str): Porque se aplica, como "sem acordo" ou "emergência".
208    """
209    dam = comportamento.agent
210    plano = dam.plano_contingencia()
211    seguro, razao = dam.validar_execucao(plano)
212    if not seguro:
213        registo.detalhe(dam.nome, f"contingência não aplicada: {razao}")
214        return
215    dam.executar_descarga(plano)
216    dam.descargas += 1
217    dam.contingencias += 1
218    metricas.descarga(plano["caudal"], plano["duracao"])
219    registo.evento(
220        "CONTINGÊNCIA",
221        f"{motivo}: caudal {plano['caudal']} durante {em_ciclos(plano['duracao'])} "
222        f"(reservatório a {dam.nivel_reservatorio:.1f}%)")
223    thread = mensagens.novo_id("cont")
224    for lider in [f"lider{b}" for b in "ABC"]:
225        if dam.rede.pode_comunicar(dam.nome, lider):
226            await comportamento.send(mensagens.criar(
227                lider, mensagens.INFORM, mensagens.NEGOCIAR_DESCARGA,
228                "aviso_contingencia", thread=thread, motivo=motivo, **plano))
229    await avisar_descarga(comportamento, plano, thread, motivo=motivo)

232class Propor(State):
233    """PROPOR: envia o plano desta rodada aos líderes."""
234
235    async def run(self):
236        """Envia a proposta da rodada a cada líder (protocolo negociar-descarga)
237        e passa a AGUARDAR. Na primeira rodada regista o início nas métricas."""
238        n = self.agent.negociacao
239        n.respostas = {}
240        for lider in n.lideres:
241            await self.send(mensagens.criar(
242                lider, mensagens.PROPOSE, mensagens.NEGOCIAR_DESCARGA,
243                "proposta_descarga", thread=n.thread,
244                id_proposta=n.id_proposta, rodada=n.rodada, **n.plano))
245        registo.detalhe(self.agent.nome,
246                        f"rodada {n.rodada} ({n.id_proposta}): plano {n.plano}")
247        if n.rodada == 1:
248            # o tempo até à decisão conta desde a primeira proposta
249            metricas.proposta(n.plano["caudal"])
250        self.set_next_state(AGUARDAR)

253class Aguardar(State):
254    """AGUARDAR: recolhe as respostas dos líderes e decide o passo seguinte."""
255
256    async def run(self):
257        """Recolhe as respostas desta rodada (ignora as de outras rodadas) e
258        escolhe o estado seguinte: ENCERRAR se há maioria ou já é a última
259        rodada, senão REFORMULAR. Quem não responde a tempo conta como "não"."""
260        n = self.agent.negociacao
261        esperados = [lider.lower() for lider in n.lideres]
262        while len(n.respostas) < len(esperados):
263            msg = await self.receive(timeout=TEMPO_ESPERA_VOTOS)
264            if msg is None:
265                break
266            r = mensagens.ler(msg)
267            if (r is None or r.tipo != "resposta_proposta"
268                    or r.remetente not in esperados
269                    or r.corpo.get("id_proposta") != n.id_proposta):
270                continue        # outra rodada, outro remetente ou lixo
271            n.respostas[r.remetente] = {
272                "aceita": r.performativa == mensagens.ACCEPT_PROPOSAL,
273                "contraproposta": r.corpo.get("contraproposta"),
274            }
275        for lider in esperados:
276            n.respostas.setdefault(lider, {"aceita": False, "contraproposta": None,
277                                           "sem_resposta": True})
278
279        favoraveis = contar_favoraveis(n.respostas)
280        if ha_maioria(favoraveis, len(esperados)) or n.rodada >= MAX_RODADAS:
281            self.set_next_state(ENCERRAR)
282        else:
283            self.set_next_state(REFORMULAR)

286class Reformular(State):
287    """REFORMULAR: baixa o caudal para a contraproposta mais restritiva."""
288
289    async def run(self):
290        """Cria o plano da rodada seguinte e volta a PROPOR. Se ninguém
291        contrapropôs, ou o novo plano não é seguro, passa a ENCERRAR."""
292        dam = self.agent
293        n = dam.negociacao
294        novo = reformular(n.plano, n.respostas)
295        if novo is None or not dam.validar_plano(novo):
296            self.set_next_state(ENCERRAR)       # ninguém contrapropôs, ou não avança
297            return
298        registo.evento(
299            "NEGOCIAÇÃO",
300            f"rodada {n.rodada}: caudal {n.plano['caudal']} | "
301            f"{resumo_respostas(n.respostas)} -> nova proposta com caudal "
302            f"{novo['caudal']}")
303        n.plano = novo
304        n.rodada += 1
305        self.set_next_state(PROPOR)

308class Encerrar(State):
309    """ENCERRAR: fecha a negociação e submete a proposta final à votação.
310
311    A proposta final é o plano da última rodada, haja ou não maioria nas
312    respostas: as respostas da negociação não vinculam, só o voto decide.
313    """

316        """Marca a negociação como "votando" e lança o behaviour `Votacao`
317        com a proposta final."""
318        dam = self.agent
319        n = dam.negociacao
320        n.fase = "votando"          # a negociação continua "ocupada" até ao fim do voto

322                                  f"{n.rodada} rodada(s): proposta final {n.plano}")
323        dam.add_behaviour(*dam.criar_votacao())

326class Votacao(OneShotBehaviour):
327    """Papel CoordenadorVotacao: vota a proposta final e executa a descarga.
328
329    Envia a proposta final aos líderes, recolhe os votos e aprova com pelo
330    menos 2 em 3 (`ha_maioria`). Regras do guia: um voto por líder em cada
331    negociação, e quem não responde a tempo conta como voto contra. Só recebe
332    mensagens do protocolo `votacao` desta negociação (template).
333    """
334
335    async def run(self):
336        """Recolhe os votos, decide e, no fim, liberta a barragem para abrir
337        outra negociação (mesmo que algo falhe)."""
338        dam = self.agent
339        n = dam.negociacao
340        try:
341            votos = await self.recolher_votos(n)
342            await self.decidir(n, votos)
343        finally:
344            dam.negociacao = None       # a barragem pode abrir outra negociação
345
346    async def recolher_votos(self, n):
347        """Pede o voto aos líderes e conta as respostas que chegam a tempo.
348
349        Args:
350            n (Negociacao): A negociação cuja proposta final se vota.
351
352        Returns:
353            dict: Voto de cada líder (nome em minúsculas), como
354            {"aceita": bool, "sem_resposta": bool}. Quem não respondeu tem
355            "aceita" falso.
356        """
357        for lider in n.lideres:
358            await self.send(mensagens.criar(
359                lider, mensagens.PROPOSE, mensagens.VOTACAO, "pedido_voto",
360                thread=n.thread, id_proposta=n.id_proposta, **n.plano))
361        esperados = [lider.lower() for lider in n.lideres]
362        votos = {}
363        while len(votos) < len(esperados):
364            msg = await self.receive(timeout=TEMPO_ESPERA_VOTOS)
365            if msg is None:
366                break
367            r = mensagens.ler(msg)
368            if (r is None or r.tipo != "voto" or r.remetente not in esperados
369                    or r.remetente in votos
370                    or r.corpo.get("id_proposta") != n.id_proposta):
371                continue        # outra negociação, um segundo voto ou lixo
372            votos[r.remetente] = {"aceita": r.performativa == mensagens.ACCEPT_PROPOSAL}
373        for lider in esperados:
374            votos.setdefault(lider, {"aceita": False, "sem_resposta": True})
375        return votos
376
377    async def decidir(self, n, votos):
378        """Conta os votos e, se a proposta foi aprovada, executa a descarga.
379
380        Args:
381            n (Negociacao): A negociação votada.
382            votos (dict): Os votos (ver `recolher_votos`).
383        """
384        dam = self.agent
385        total = len(n.lideres)
386        favoraveis = contar_favoraveis(votos)
387        aprovado = ha_maioria(favoraveis, total)
388        plano = n.plano
389        metricas.decisao(aprovado, favoraveis, total)
390        rodadas = f" | {n.rodada} rodadas" if n.rodada > 1 else ""
391        registo.evento(
392            "VOTAÇÃO",
393            f"caudal {plano['caudal']} (atraso {plano['atraso']}, duração "
394            f"{em_ciclos(plano['duracao'])}) | {resumo_respostas(votos)} | "
395            f"{favoraveis}/{total} -> "
396            + ("aprovado" if aprovado else "rejeitado, nada foi executado")
397            + rodadas)
398        dam.negociacoes.append({"thread": n.thread, "rodadas": n.rodada,
399                                "aprovada": aprovado, "caudal": plano["caudal"]})
400
401        if not aprovado:
402            dam.rejeitados += 1
403            await self.sem_execucao("sem acordo")
404            return
405
406        # a votação nunca autoriza uma operação insegura: valida-se de novo
407        # com o estado atual, porque a negociação e o voto demoraram
408        seguro, razao = dam.validar_execucao(plano)
409        if not seguro:
410            metricas.rejeitada_seguranca(razao)
411            registo.evento("SEGURANÇA",
412                           f"plano aprovado mas não executado: {razao}")
413            await self.sem_execucao("plano aprovado inseguro")
414            return
415
416        dam.executar_descarga(plano)
417        dam.descargas += 1
418        metricas.descarga(plano["caudal"], plano["duracao"])
419        registo.evento(
420            "DESCARGA",
421            f"caudal {plano['caudal']} durante {em_ciclos(plano['duracao'])} "
422            f"(reservatório a {dam.nivel_reservatorio:.1f}%)")
423        await avisar_descarga(self, plano, n.thread)
424
425    async def sem_execucao(self, motivo):
426        """A descarga não se fez: aplica a contingência se o reservatório já
427        está tão cheio que esperar pela próxima verificação seria arriscado.
428
429        Args:
430            motivo (str): Porque não houve descarga normal.
431        """
432        if self.agent.precisa_contingencia():
433            await executar_contingencia(self, motivo)

439    async def on_end(self):
440        """Chamado quando o FSM acaba. Se a negociação falhou antes da votação,
441        liberta a barragem para abrir outra."""
442        # Se um estado falhou, a negociação nunca chegou à votação: liberta a
443        # barragem para abrir outra. Se chegou, é a votação que a liberta.
