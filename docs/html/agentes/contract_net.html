agentes.contract_net

Contratação de serviços entre bairros: FIPA Contract Net (secção 5.3 do guia).

Os dois lados vivem no agente líder (agentes/lider.py), porque um bairro pode comprar num momento e vender noutro (papéis Comprador e Fornecedor).

Comprador: um FSMBehaviour por contratação (ContractNetComprador), com um estado por etapa, como pede a secção 9.4 do modelo Gaia:

CONSULTAR -> CHAMAR -> NEGOCIAR -> AGUARDAR -> ENCERRAR
    |           |          |
    +-----------+----------+--> ENCERRAR (sem ofertas, sem propostas, sem acordo)
  • CONSULTAR: pede ao diretório as ofertas do serviço (ConsultarOfertas).
  • CHAMAR: envia o CFP aos fornecedores encontrados e recolhe PROPOSE/REFUSE.
  • NEGOCIAR: começa pela proposta mais barata. Aceita, contrapropõe (abre com 60% do preço base) ou desiste e passa ao fornecedor seguinte. Com acordo, rejeita as restantes propostas.
  • AGUARDAR: espera que o fornecedor confirme a execução. Só então paga (regra 4: pagamento só depois de ConfirmarServico). FAILURE: não paga.
  • ENCERRAR: regista o resultado; on_end liberta o serviço para nova compra.

Fornecedor: Vendas guarda as vendas em curso, por thread, e reage a cada mensagem (é chamado pelo CyclicBehaviour FornecedorServicos do líder):

CFP -> PROPOSE (preço base) ou REFUSE (sem excedente, regra 7)
PROPOSE do comprador -> ACCEPT-PROPOSAL (>= 70%, reserva) ou PROPOSE (contraproposta)
ACCEPT-PROPOSAL do comprador -> reserva e pede a execução ao operador
INFORM/FAILURE do operador -> ConfirmarServico ao comprador (INFORM ou
                              FAILURE; na falha liberta a reserva)
INFORM "pagamento" -> recebe a moeda

As regras de preço e de reserva estão em mercado.py.

Todas as mensagens de uma contratação levam o mesmo thread ("cn-B-001"), que é o id da negociação. O SPADE entrega uma mensagem a todos os behaviours cujo template coincide, por isso Vendas ignora threads que não conhece (são compras do próprio líder) e o FSM do comprador só recebe o seu thread.

 60class Compra:
 61    """Uma contratação em curso, do lado do comprador.
 62
 63    Attributes:
 64        thread (str): Id da negociação, como "cn-B-001".
 65        servico (str): Recurso a contratar, como "bombas".

 78    servico: str
 79    quantidade: int
 80    fornecedores: list = field(default_factory=list)
 81    propostas: list = field(default_factory=list)
 82    fornecedor: str | None = None
 83    preco: float | None = None
 84    quantidade_acordada: int = 0
 85    resultado: str = "em curso"
 86    rodadas: int = 0

 94async def esperar(state, aceitar, timeout):
 95    """Recebe mensagens até chegar uma que interesse ou acabar o tempo.
 96
 97    Args:
 98        state (State): O estado do FSM que espera.
 99        aceitar (callable): Recebe uma `mensagens.Recebida` e devolve True se
100            for a mensagem esperada. As outras são descartadas.
101        timeout (float): Segundos de espera, no total.
102
103    Returns:
104        mensagens.Recebida | None: A mensagem, ou None se o tempo acabou.
105    """
106    limite = time.monotonic() + timeout
107    while (falta := limite - time.monotonic()) > 0:
108        msg = mensagens.ler(await state.receive(timeout=falta))
109        if msg is None:
110            return None
111        if aceitar(msg):
112            return msg
113    return None

116class Consultar(State):
117    """CONSULTAR: pede ao diretório quem vende o serviço."""
118
119    async def run(self):
120        """Envia ConsultarOfertas e guarda a lista de fornecedores.
121        Sem ofertas, passa a ENCERRAR."""
122        lider, c = self.agent, self.agent.compras[self.servico]
123        await self.send(mensagens.criar(
124            "diretorio", mensagens.REQUEST, mensagens.CONSULTAR_OFERTAS,
125            "consultar_ofertas", thread=c.thread, servico=c.servico))
126        resposta = await esperar(
127            self, lambda m: m.protocolo == mensagens.CONSULTAR_OFERTAS, TEMPO_ESPERA_CN)
128        ofertas = resposta.corpo.get("ofertas", []) if resposta else []
129        for oferta in ofertas:
130            nome = oferta["fornecedor"]
131            if nome not in c.fornecedores and lider.rede.pode_comunicar(lider.nome, nome):
132                c.fornecedores.append(nome)
133        if not c.fornecedores:
134            c.resultado = "sem ofertas no diretório"
135            self.set_next_state(ENCERRAR)
136            return
137        registo.detalhe(lider.nome, f"{c.thread}: {c.servico} à venda em "
138                                    f"{', '.join(c.fornecedores)}")
139        self.set_next_state(CHAMAR)

142class Chamar(State):
143    """CHAMAR: envia o CFP e recolhe as propostas."""
144
145    async def run(self):
146        """Envia o CFP a todos os fornecedores e espera PROPOSE ou REFUSE de
147        cada um (quem não responde a tempo fica de fora)."""
148        c = self.agent.compras[self.servico]
149        for fornecedor in c.fornecedores:
150            await self.send(mensagens.criar(
151                fornecedor, mensagens.CFP, mensagens.CONTRACT_NET, "cfp",
152                thread=c.thread, servico=c.servico, quantidade=c.quantidade))
153        pendentes = set(c.fornecedores)
154        while pendentes:
155            msg = await esperar(
156                self, lambda m: m.protocolo == mensagens.CONTRACT_NET
157                and m.remetente in pendentes
158                and m.performativa in (mensagens.PROPOSE, mensagens.REFUSE),
159                TEMPO_ESPERA_CN)
160            if msg is None:
161                break
162            pendentes.discard(msg.remetente)
163            if msg.performativa == mensagens.PROPOSE:
164                c.propostas.append({"fornecedor": msg.remetente,
165                                    "preco": float(msg.corpo["preco"]),
166                                    "quantidade": int(msg.corpo["quantidade"])})
167        c.propostas.sort(key=lambda p: (p["preco"], -p["quantidade"], p["fornecedor"]))
168        if not c.propostas:
169            c.resultado = "nenhum fornecedor fez proposta"
170            self.set_next_state(ENCERRAR)
171            return
172        self.set_next_state(NEGOCIAR)

175class Negociar(State):
176    """NEGOCIAR: contrapropostas com cada fornecedor, do mais barato ao mais caro."""
177
178    async def run(self):
179        """Tenta um acordo com cada proposta, por ordem de preço. Com acordo,
180        rejeita as restantes e passa a AGUARDAR; sem acordo, a ENCERRAR."""
181        lider, c = self.agent, self.agent.compras[self.servico]
182        for indice, proposta in enumerate(c.propostas):
183            if await self.negociar_com(proposta):
184                for outra in c.propostas[indice + 1:]:
185                    await self.send(self.mensagem(outra["fornecedor"],
186                                                  mensagens.REJECT_PROPOSAL,
187                                                  "rejeicao", motivo="outra proposta"))
188                lider.moeda_comprometida += c.total
189                registo.evento("CONTRATO", f"bairro {lider.bairro} contratou "
190                               f"{c.servico} x{c.quantidade_acordada} ao bairro "
191                               f"{c.fornecedor[-1].upper()} a {c.preco:.2f}/un. "
192                               f"(base {mercado.preco_base(c.servico):.0f}, "
193                               f"{c.rodadas} rodada(s))")
194                self.set_next_state(AGUARDAR)
195                return
196        c.resultado = "sem acordo de preço"
197        self.set_next_state(ENCERRAR)
198
199    def mensagem(self, para, performativa, tipo, **dados):
200        """Mensagem ao fornecedor nesta contratação (protocolo e thread)."""
201        c = self.agent.compras[self.servico]
202        return mensagens.criar(para, performativa, mensagens.CONTRACT_NET, tipo,
203                               thread=c.thread, servico=c.servico, **dados)
204
205    async def negociar_com(self, proposta):
206        """Rodadas de contraproposta com um fornecedor.
207
208        Args:
209            proposta (dict): {fornecedor, preco, quantidade} recebida no CHAMAR.
210
211        Returns:
212            bool: True se houve acordo (fica guardado na `Compra`).
213        """
214        lider, c = self.agent, self.agent.compras[self.servico]
215        fornecedor, quantidade = proposta["fornecedor"], proposta["quantidade"]
216        preco_pedido, ultima_oferta, rodada = proposta["preco"], None, 1
217        while True:
218            disponivel = lider.estado.moeda - lider.moeda_comprometida
219            decisao, preco = mercado.decisao_comprador(
220                c.servico, preco_pedido, quantidade, disponivel, rodada, ultima_oferta)
221            if decisao == mercado.DESISTIR:
222                await self.send(self.mensagem(fornecedor, mensagens.REJECT_PROPOSAL,
223                                              "rejeicao", motivo="preço"))
224                registo.detalhe(lider.nome, f"{c.thread}: desistiu de {fornecedor} "
225                                            f"(pedia {preco_pedido})")
226                return False
227            if decisao == mercado.ACEITAR:
228                await self.send(self.mensagem(fornecedor, mensagens.ACCEPT_PROPOSAL,
229                                              "aceitacao", preco=preco,
230                                              quantidade=quantidade))
231                self.fechar(fornecedor, preco, quantidade, rodada)
232                return True
233
234            # contraproposta do comprador
235            await self.send(self.mensagem(fornecedor, mensagens.PROPOSE,
236                                          "contraproposta", preco=preco,
237                                          quantidade=quantidade, rodada=rodada))
238            registo.detalhe(lider.nome, f"{c.thread}: rodada {rodada}, {fornecedor} "
239                                        f"pede {preco_pedido}, oferece {preco}")
240            ultima_oferta = preco
241            resposta = await esperar(
242                self, lambda m: m.protocolo == mensagens.CONTRACT_NET
243                and m.remetente == fornecedor
244                and m.performativa in (mensagens.ACCEPT_PROPOSAL, mensagens.PROPOSE,
245                                       mensagens.REFUSE, mensagens.FAILURE),
246                TEMPO_ESPERA_CN)
247            if resposta is None or resposta.performativa in (mensagens.REFUSE,
248                                                             mensagens.FAILURE):
249                return False
250            if resposta.performativa == mensagens.ACCEPT_PROPOSAL:
251                # o fornecedor aceitou a contraproposta e já reservou
252                self.fechar(fornecedor, preco, int(resposta.corpo.get("quantidade",
253                                                                      quantidade)), rodada)
254                return True
255            preco_pedido = float(resposta.corpo["preco"])       # nova contraproposta
256            rodada += 1
257
258    def fechar(self, fornecedor, preco, quantidade, rodada):
259        """Guarda o acordo na `Compra`."""
260        c = self.agent.compras[self.servico]
261        c.fornecedor, c.preco, c.quantidade_acordada, c.rodadas = (
262            fornecedor, preco, quantidade, rodada)

265class Aguardar(State):
266    """AGUARDAR: espera a confirmação da execução e só então paga."""
267
268    async def run(self):
269        """INFORM "servico_confirmado": paga (moeda do comprador desce) e
270        envia o Pagamento. FAILURE ou silêncio: não paga (regra 4)."""
271        lider, c = self.agent, self.agent.compras[self.servico]
272        msg = await esperar(
273            self, lambda m: m.protocolo == mensagens.CONTRACT_NET
274            and m.remetente == c.fornecedor
275            and m.performativa in (mensagens.INFORM, mensagens.FAILURE),
276            TEMPO_ESPERA_EXECUCAO)
277        lider.moeda_comprometida = max(0.0, lider.moeda_comprometida - c.total)
278        if msg is None or msg.performativa == mensagens.FAILURE:
279            motivo = msg.corpo.get("motivo", "falha") if msg else "sem confirmação"
280            c.resultado = f"serviço falhou ({motivo}), sem pagamento"
281            registo.evento("CONTRATO", f"bairro {lider.bairro}: {c.servico} de "
282                                       f"{c.fornecedor} falhou ({motivo}); não paga")
283            self.set_next_state(ENCERRAR)
284            return
285
286        lider.estado.moeda = round(lider.estado.moeda - c.total, 2)
287        await self.send(mensagens.criar(
288            c.fornecedor, mensagens.INFORM, mensagens.CONTRACT_NET, "pagamento",
289            thread=c.thread, servico=c.servico, valor=c.total))
290        metricas.transacao(lider.bairro, c.fornecedor[-1].upper(), c.servico,
291                           c.quantidade_acordada, c.preco)
292        c.resultado = "pago"
293        registo.evento("PAGAMENTO", f"bairro {lider.bairro} pagou {c.total:.2f} ao "
294                                    f"bairro {c.fornecedor[-1].upper()} "
295                                    f"(saldo {lider.estado.moeda:.2f})")
296        self.set_next_state(ENCERRAR)

309class ContractNetComprador(FSMBehaviour):
310    """Uma contratação de um serviço, do lado do comprador.
311
312    Attributes:
313        servico (str): O serviço contratado (chave em `lider.compras`).
314    """
315
316    def __init__(self, servico):
317        """Cria o FSM com os estados do Contract Net.
318
319        Args:
320            servico (str): O serviço a contratar.
321        """
322        super().__init__()
323        self.servico = servico
324        for nome, estado, inicial in ((CONSULTAR, Consultar(), True),
325                                      (CHAMAR, Chamar(), False),
326                                      (NEGOCIAR, Negociar(), False),
327                                      (AGUARDAR, Aguardar(), False),
328                                      (ENCERRAR, Encerrar(), False)):
329            estado.servico = servico
330            self.add_state(nome, estado, initial=inicial)
331        for origem, destino in ((CONSULTAR, CHAMAR), (CONSULTAR, ENCERRAR),
332                                (CHAMAR, NEGOCIAR), (CHAMAR, ENCERRAR),
333                                (NEGOCIAR, AGUARDAR), (NEGOCIAR, ENCERRAR),
334                                (AGUARDAR, ENCERRAR)):
335            self.add_transition(origem, destino)
336
337    async def on_end(self):
338        """Liberta o serviço para uma nova compra e guarda o histórico."""
339        compra = self.agent.compras.pop(self.servico, None)
340        if compra is not None:
341            self.agent.historico_compras.append(compra)

383class Vendas:
384    """O papel Fornecedor do líder: responde ao Contract Net dos outros bairros.
385
386    Cada método recebe uma mensagem já lida e devolve a lista de mensagens a
387    enviar, para o behaviour as enviar e para se poder testar sem rede.
388
389    Attributes:
390        lider (CommunityLeader): O líder dono destas vendas.
391        abertas (dict): Vendas em curso, por thread.
392    """
393
394    def __init__(self, lider):
395        """Cria o registo de vendas vazio.
396
397        Args:
398            lider (CommunityLeader): O líder fornecedor.
399        """
400        self.lider = lider
401        self.abertas = {}
402
403    def tratar(self, msg):
404        """Encaminha uma mensagem do Contract Net ou do operador.
405
406        Args:
407            msg (mensagens.Recebida): Mensagem recebida pelo líder.
408
409        Returns:
410            list: Mensagens a enviar (pode ser vazia).
411        """
412        if msg.protocolo == mensagens.EXECUTAR_SERVICO:
413            return self.resultado_execucao(msg)
414        if msg.performativa == mensagens.CFP:
415            return self.cfp(msg)
416        venda = self.abertas.get(msg.thread)
417        if venda is None or msg.remetente != venda.comprador:
418            return []               # compra do próprio líder, ou lixo
419        if msg.performativa == mensagens.PROPOSE and venda.fase == "negociando":
420            return self.contraproposta(venda, msg)
421        if msg.performativa == mensagens.ACCEPT_PROPOSAL and venda.fase == "negociando":
422            return self.aceite_pelo_comprador(venda, msg)
423        if msg.performativa == mensagens.REJECT_PROPOSAL and venda.fase == "negociando":
424            del self.abertas[venda.thread]
425            return []
426        if msg.performativa == mensagens.INFORM and msg.tipo == "pagamento":
427            return self.pagamento(venda, msg)
428        return []
429
430    def _para_comprador(self, venda, performativa, tipo, **dados):
431        """Mensagem ao comprador, no thread da venda."""
432        return mensagens.criar(venda.comprador, performativa, mensagens.CONTRACT_NET,
433                               tipo, thread=venda.thread, servico=venda.servico, **dados)
434
435    def cfp(self, msg):

438        servico, pedida = msg.corpo.get("servico"), int(msg.corpo.get("quantidade", 0))
439        if not lider.rede.pode_comunicar(lider.nome, msg.remetente):
440            return []

442        quantidade = min(pedida, disponivel)
443        if quantidade <= 0:
444            return [mensagens.criar(msg.remetente, mensagens.REFUSE,
445                                    mensagens.CONTRACT_NET, "recusa", thread=msg.thread,
446                                    servico=servico, motivo="sem excedente")]
447        venda = Venda(msg.thread, msg.remetente, servico, quantidade,
448                      mercado.preco_pedido_inicial(servico))
449        self.abertas[msg.thread] = venda
450        return [self._para_comprador(venda, mensagens.PROPOSE, "proposta",
451                                     preco=venda.preco, quantidade=quantidade)]
452
453    def contraproposta(self, venda, msg):
454        """Contraproposta do comprador: aceita a partir de 70% (regra 9),
455        senão contrapõe."""
456        oferta = float(msg.corpo["preco"])
457        if mercado.vendedor_aceita(venda.servico, oferta):
458            venda.preco = oferta
459            return self.reservar_e_executar(venda, avisar_aceite=True)
460        venda.preco = mercado.contraproposta_vendedor(venda.servico, venda.preco, oferta)
461        return [self._para_comprador(venda, mensagens.PROPOSE, "proposta",
462                                     preco=venda.preco, quantidade=venda.quantidade)]

464    def aceite_pelo_comprador(self, venda, msg):

466        if not mercado.vendedor_aceita(venda.servico, float(msg.corpo.get("preco", 0))):
467            del self.abertas[venda.thread]
468            return [self._para_comprador(venda, mensagens.FAILURE, "falha",
469                                         motivo="preço diferente do proposto")]
470        return self.reservar_e_executar(venda, avisar_aceite=False)

472    def reservar_e_executar(self, venda, avisar_aceite):
473        """Passos 4 e 5 do Contract Net: reserva o recurso e pede ao operador
474        do bairro que execute o serviço no bairro comprador.
475
476        A reserva volta a verificar a regra 7 com o estoque atual (outra venda
477        pode ter reservado entretanto).
478
479        Args:
480            venda (Venda): A venda acordada.
481            avisar_aceite (bool): Se True, envia ACCEPT-PROPOSAL ao comprador
482                (foi o fornecedor que aceitou a contraproposta).
483
484        Returns:
485            list: Mensagens a enviar.
486        """
487        lider = self.lider
488        operador = f"op{lider.bairro}"
489        if (not mercado.pode_oferecer(lider.estado, venda.servico, venda.quantidade,
490                                      lider.risco_do_bairro)
491                or not lider.rede.pode_comunicar(lider.nome, operador)

513        na falha, liberta a reserva e avisa o comprador."""

513        """Resposta do operador: confirma ao comprador (ConfirmarServico) ou,
514        na falha, liberta a reserva e avisa o comprador."""
515        venda = self.abertas.get(msg.thread)
516        if venda is None or venda.fase != "executando":
517            return []
518        if msg.performativa == mensagens.AGREE:
519            return []
520        if msg.performativa == mensagens.INFORM:
521            venda.fase = "confirmada"
522            return [self._para_comprador(venda, mensagens.INFORM, "servico_confirmado",
523                                         quantidade=venda.quantidade, preco=venda.preco)]
524        # FAILURE: a reserva volta ao estoque livre e não há pagamento
525        self.lider.estado.libertar(venda.servico, venda.quantidade)
526        del self.abertas[venda.thread]
527        motivo = msg.corpo.get("motivo", "falha na execução")
