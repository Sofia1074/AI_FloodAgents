metricas

Recolha das métricas de avaliação (secção 7 do guia).

Métricas recolhidas:

  • tempo de deteção: ciclos entre um bairro chegar de facto a risco elevado (calculado no ambiente com as regras de risco.py) e o operador alertar;
  • mensagens trocadas, por performativa;
  • tempo até à decisão coletiva: segundos entre a proposta da barragem e o resultado da votação (medido com time.perf_counter: no Windows o time.monotonic só tem resolução de 15,6 ms e dava 0 ms);
  • utilização dos recursos de mitigação, por bairro;
  • evolução do risco: nível, velocidade e risco de cada bairro em cada ciclo;
  • propostas aprovadas, rejeitadas na votação e rejeitadas por segurança, e descargas de contingência (que não passam por proposta nem votação);
  • transações entre bairros e preços negociados.

Uso: main.py chama iniciar() no arranque, registar_ciclo() a cada passo do ambiente e exportar() no fim. Os agentes chamam os ganchos (alerta, mitigacao, proposta, decisao, rejeitada_seguranca, descarga, contingencia, transacao). Sem iniciar() os ganchos não fazem nada, por isso os agentes funcionam também fora de uma simulação (por exemplo, nos testes).

As mensagens contam-se sem mexer nos agentes: instalar_contador_mensagens() embrulha o método send dos behaviours do SPADE (todos o herdam de CyclicBehaviour).

Ficheiros exportados para a pasta do cenário: ciclos.csv uma linha por ciclo do ambiente eventos.csv alertas, mitigações, propostas, decisões, descargas... resumo.json os totais de cada métrica

 53    def __init__(self, cenario, ambiente):
 54        """Cria uma recolha vazia.
 55
 56        Args:
 57            cenario (str): Nome do cenário (fica no resumo).
 58            ambiente (ambiente.Ambiente): O ambiente da simulação.
 59        """
 60        self.cenario = cenario
 61        self.ambiente = ambiente
 62        self.inicio = time.perf_counter()
 63        self.ciclos = []                 # uma linha (dict) por ciclo
 64        self.eventos = []                # um dict por evento
 65        self.inicio_risco_real = {}      # bairro -> 1.º ciclo em risco elevado
 66        self.mensagens = Counter()       # performativa -> quantidade
 67        self.mensagens_por_agente = Counter()

 69    # ---- ciclos ----------------------------------------------------------
 70
 71    def registar_ciclo(self):
 72        """Guarda o estado do ambiente depois de um passo, com o risco real
 73        de cada bairro (as mesmas regras que o operador usa)."""
 74        amb = self.ambiente
 75        linha = {
 76            "ciclo": amb.ciclo,
 77            "segundos": round(self._agora(), 2),
 78            "chuva": amb.chuva_ultimo_ciclo,
 79            "reservatorio": round(amb.nivel_reservatorio, 2),
 80            "caudal_entrada": round(amb.caudal_entrada, 2),
 81            "caudal_saida": round(amb.caudal_saida, 2),
 82        }
 83        for nome, b in amb.bairros.items():
 84            risco, _ = classificar_risco(
 85                nivel=b.nivel, velocidade=b.velocidade,
 86                entrada_chuva=b.entrada_chuva(amb.chuva_ultimo_ciclo),
 87                drenagem=b.drenagem_natural())
 88            linha[f"nivel_{nome}"] = round(b.nivel, 2)
 89            linha[f"velocidade_{nome}"] = round(b.velocidade, 2)
 90            linha[f"humidade_{nome}"] = round(b.humidade, 3)
 91            linha[f"risco_{nome}"] = risco
 92            if risco in RISCOS_ALTOS and nome not in self.inicio_risco_real:
 93                self.inicio_risco_real[nome] = amb.ciclo
 94        self.ciclos.append(linha)

 98    def mensagem(self, remetente, performativa):

101        Args:
102            remetente (str): Nome do agente que enviou.

104        """

122            recursos (dict): Quantidade ativada por recurso, como {"bombas": 2}.
123        """

126    def proposta(self, caudal):

173        Args:
174            comprador (str): Bairro que pagou.
175            fornecedor (str): Bairro que forneceu.
176            servico (str): Serviço contratado, como "bombas".
177            quantidade (int): Unidades contratadas.
178            preco (float): Preço por unidade.

183    # ---- resultados ------------------------------------------------------

185    def resumo(self):
186        """Devolve os totais de todas as métricas num dicionário.
187
188        Returns:
189            dict: O conteúdo do `resumo.json` (deteção, mensagens, tempo até
190            à decisão, propostas, recursos, transações e níveis).
191        """
192        bairros = list(self.ambiente.bairros)
193        por_tipo = {}
194        for e in self.eventos:
195            por_tipo.setdefault(e["tipo"], []).append(e)
196
197        deteccao = {}
198        for b in bairros:
199            inicio = self.inicio_risco_real.get(b)
200            alertas = [e["ciclo"] for e in por_tipo.get("alerta", [])
201                       if e["bairro"] == b and e["risco"] in RISCOS_ALTOS
202                       and inicio is not None and e["ciclo"] >= inicio]
203            deteccao[b] = alertas[0] - inicio if alertas else None
204
205        tempos_decisao, pendente = [], None
206        for e in self.eventos:
207            if e["tipo"] == "proposta":
208                pendente = e["segundos"]
209            elif e["tipo"] == "decisao" and pendente is not None:
210                tempos_decisao.append(round(e["segundos"] - pendente, 4))
211                pendente = None
212
213        recursos_bairro = {b: Counter() for b in bairros}
214        for e in por_tipo.get("mitigacao", []):
215            recursos_bairro[e["bairro"]].update(e["recursos"])
216        total_recursos = sum(recursos_bairro.values(), Counter())
217
218        precos = {}
219        for e in por_tipo.get("transacao", []):
220            precos.setdefault(e["servico"], []).append(e["preco"])
221
222        decisoes = por_tipo.get("decisao", [])
223        return {
224            "cenario": self.cenario,
225            "ciclos": len(self.ciclos),
226            "duracao_s": round(self._agora(), 1),
227            "tempo_deteccao_ciclos": deteccao,
228            "tempo_deteccao_s": {b: (None if c is None else c * PERIODO_CICLO)
229                                 for b, c in deteccao.items()},
230            "mensagens": {"total": sum(self.mensagens.values()),
231                          "por_performativa": dict(self.mensagens),
232                          "por_agente": dict(self.mensagens_por_agente)},
233            "tempo_ate_decisao_s": tempos_decisao,
234            "propostas": {
235                "total": len(por_tipo.get("proposta", [])),
236                "aprovadas": sum(1 for e in decisoes if e["aprovado"]),
237                "rejeitadas_votacao": sum(1 for e in decisoes if not e["aprovado"]),
238                "rejeitadas_seguranca": len(por_tipo.get("rejeitada_seguranca", [])),
239                "descargas": len(por_tipo.get("descarga", [])),
240                "contingencias": len(por_tipo.get("contingencia", [])),
241            },
242            "recursos": {"total": dict(total_recursos),
243                         "por_bairro": {b: dict(c) for b, c in recursos_bairro.items()}},
244            "transacoes": {"total": len(por_tipo.get("transacao", [])),
245                           "preco_medio": {s: round(sum(p) / len(p), 2)
246                                           for s, p in precos.items()}},
247            "alertas": len(por_tipo.get("alerta", [])),
248            "nivel_maximo": {b: max((l[f"nivel_{b}"] for l in self.ciclos), default=0.0)
249                             for b in bairros},
250            "ciclos_em_risco_elevado": {
251                b: sum(1 for l in self.ciclos if l[f"risco_{b}"] in RISCOS_ALTOS)
252                for b in bairros},
253        }
254
255    def exportar(self, pasta):
256        """Escreve ciclos.csv, eventos.csv e resumo.json em `pasta`.
257
258        Args:
259            pasta (str): Pasta de destino (criada se não existir).
260        """
261        os.makedirs(pasta, exist_ok=True)
262        if self.ciclos:
263            with open(os.path.join(pasta, "ciclos.csv"), "w", newline="",
264                      encoding="utf-8") as f:
265                escritor = csv.DictWriter(f, fieldnames=list(self.ciclos[0]))
266                escritor.writeheader()
267                escritor.writerows(self.ciclos)
268        with open(os.path.join(pasta, "eventos.csv"), "w", newline="",
269                  encoding="utf-8") as f:
270            escritor = csv.writer(f)
271            escritor.writerow(["ciclo", "segundos", "tipo", "bairro", "detalhe"])
272            for e in self.eventos:
273                extra = {k: v for k, v in e.items()
274                         if k not in ("ciclo", "segundos", "tipo", "bairro")}
275                escritor.writerow([e["ciclo"], e["segundos"], e["tipo"],
276                                   e.get("bairro", ""), json.dumps(extra, ensure_ascii=False)])
277        with open(os.path.join(pasta, "resumo.json"), "w", encoding="utf-8") as f:
278            json.dump(self.resumo(), f, ensure_ascii=False, indent=2)

334def _gancho(nome):
335    """Cria a função do módulo que passa a chamada ao método `nome` da
336    recolha em curso, e não faz nada se não houver nenhuma."""
337    def chamar(*args, **kwargs):
338        """Chama o método da recolha em curso, se houver."""
339        if _atual is not None:
340            getattr(_atual, nome)(*args, **kwargs)
341    chamar.__name__ = nome
342    chamar.__doc__ = f"Passa para Recolha.{nome} se houver uma recolha em curso."
343    return chamar

358def instalar_contador_mensagens(classe_behaviour=None):
359    """Passa a contar todas as mensagens enviadas pelos behaviours.
360
361    Embrulha `send` de `classe_behaviour` (por omissão o CyclicBehaviour do
362    SPADE, de onde todos os behaviours herdam). Chamar duas vezes não
363    conta a dobrar.
364
365    Args:
366        classe_behaviour (type | None): Classe cujo `send` se embrulha.
367    """
368    if classe_behaviour is None:
369        from spade.behaviour import CyclicBehaviour
370        classe_behaviour = CyclicBehaviour
371    original = classe_behaviour.send
372    if getattr(original, "_conta_mensagens", False):
373        return
374
375    async def send(self, msg):
376        """Conta a mensagem e envia-a com o `send` original do SPADE.
377
378        Args:
379            msg (Message): A mensagem a enviar.
380
381        Returns:
382            O resultado do `send` original.
383        """
384        agente = getattr(getattr(self, "agent", None), "name", "?")
385        mensagem(str(agente), msg.get_metadata("performative"))
386        return await original(self, msg)
387
388    send._conta_mensagens = True
389    classe_behaviour.send = send
